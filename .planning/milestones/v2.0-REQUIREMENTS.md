## v2.0 Requirements: Simulator Control Platform (COMPLETE)

Requirements for real-time monitoring and control platform enabling observable, controllable testing infrastructure.

### Backend Infrastructure (8/8 complete)

- [x] **BACK-01**: ASP.NET Core REST API for configuration and control operations
- [x] **BACK-02**: SignalR WebSocket hub for real-time bi-directional communication
- [x] **BACK-03**: SQLite database with EF Core for historical data persistence
- [x] **BACK-04**: Health check endpoints for all protocol servers (FTP, SFTP, HTTP, S3, SMB, NAS, Kafka)
- [x] **BACK-05**: FileSystemWatcher integration for Windows directory monitoring
- [x] **BACK-06**: KubernetesClient integration for dynamic resource management
- [x] **BACK-07**: RBAC ServiceAccount with permissions for deployment/service CRUD operations
- [x] **BACK-08**: Configuration persistence across pod restarts

### Frontend Dashboard (8/8 complete)

- [x] **DASH-01**: React 19 + Vite SPA with TypeScript
- [x] **DASH-02**: SignalR client connection with reconnection logic
- [x] **DASH-03**: Server health status grid showing all protocol servers
- [x] **DASH-04**: Real-time event feed display (WebSocket-driven updates)
- [x] **DASH-05**: File browser interface with directory navigation
- [x] **DASH-06**: Usage metrics visualization (charts using Recharts)
- [x] **DASH-07**: Historical data timeline (7-day retention display)
- [x] **DASH-08**: Protocol-specific connection details panel

### Real-Time Monitoring (8/8 complete)

- [x] **MON-01**: Protocol-specific health checks (TCP + application-level validation)
- [x] **MON-02**: Real-time server status updates (5-second granularity)
- [x] **MON-03**: Connection quality metrics (latency, success rate)
- [x] **MON-04**: File event streaming (arrivals and departures)
- [x] **MON-05**: Windows directory watcher with debouncing (prevent buffer overflow)
- [x] **MON-06**: Protocol access logging (track which protocol accessed which files)
- [x] **MON-07**: Multi-protocol event correlation (trace file journey)
- [x] **MON-08**: Historical event retention (7 days in SQLite)

### File Operations (7/7 complete)

- [x] **FILE-01**: Browse Windows directories through UI (C:\simulator-data hierarchy)
- [x] **FILE-02**: Download files from any protocol server through browser
- [x] **FILE-03**: Upload files to any protocol server through UI
- [x] **FILE-04**: Delete files across protocols from dashboard
- [x] **FILE-05**: File metadata display (size, modified date, permissions)
- [x] **FILE-06**: Bulk file operations (multi-select support)
- [x] **FILE-07**: Cross-protocol file tracking (show which protocols can see file)

### Kafka Integration (9/9 complete)

- [x] **KAFKA-01**: Kafka broker deployment (Zookeeper mode)
- [x] **KAFKA-02**: Minimal resource configuration (768Mi-1GB heap)
- [x] **KAFKA-03**: Topic creation through UI with partition/replication configuration
- [x] **KAFKA-04**: Topic deletion through UI
- [x] **KAFKA-05**: Topic listing with metadata (partitions, replication factor, retention)
- [x] **KAFKA-06**: Basic pub/sub testing (produce messages to topics)
- [x] **KAFKA-07**: Consume messages from topics (view message content)
- [x] **KAFKA-08**: Consumer group monitoring (offsets, lag, members)
- [x] **KAFKA-09**: Health checks for Kafka broker and topics

### Dynamic Control (9/9 complete)

- [x] **CTRL-01**: Add new FTP server instance at runtime through UI
- [x] **CTRL-02**: Add new SFTP server instance at runtime through UI
- [x] **CTRL-03**: Add new NAS server instance at runtime through UI
- [x] **CTRL-04**: Remove server instances dynamically (with orphaned resource cleanup)
- [x] **CTRL-05**: Kubernetes ownerReferences for all dynamically created resources
- [x] **CTRL-06**: ConfigMap updates for service discovery when servers added/removed
- [x] **CTRL-07**: Server lifecycle management (start/stop/restart individual servers)
- [x] **CTRL-08**: Resource quota enforcement (prevent runaway server creation)
- [x] **CTRL-09**: Validation and guardrails (prevent invalid configurations)

### Configuration Management (7/7 complete)

- [x] **CFG-01**: Export current simulator configuration to JSON file
- [x] **CFG-02**: Import configuration from JSON file
- [x] **CFG-03**: Configuration validation before import
- [x] **CFG-04**: Configuration templates for common scenarios (basic, multi-nas, kafka-enabled)
- [x] **CFG-05**: Version control friendly format (readable JSON with comments)
- [x] **CFG-06**: Audit log of configuration changes (who, what, when)
- [x] **CFG-07**: Team configuration sharing (export includes all servers + settings)

### Alerting & Notifications (6/6 complete)

- [x] **ALERT-01**: Server health degradation alerts (connection failures, high latency)
- [x] **ALERT-02**: File system alerts (disk space warnings for Windows directories)
- [x] **ALERT-03**: Event volume anomaly detection (unusual file activity)
- [x] **ALERT-04**: Kafka broker health alerts
- [x] **ALERT-05**: Real-time notification display in dashboard (toast notifications)
- [x] **ALERT-06**: Alert history log (what triggered, when resolved)
