1. In `ServerCard.tsx`, derive a protocol CSS class from the server's protocol. After the existing `healthState` and `healthText` declarations (around line 49), add:

```typescript
// Derive protocol class for tinted background (VIS-01)
const protocolClass = `server-card--protocol-${server.protocol.toLowerCase()}`;
```

Note: `server.protocol` is typed as `Protocol` which is `'FTP' | 'SFTP' | 'HTTP' | 'S3' | 'SMB' | 'NFS' | 'Management'`. The `.toLowerCase()` produces `ftp`, `sftp`, `http`, `s3`, `smb`, `nfs`, or `management`. The CSS only defines rules for `ftp` through `nas` — `management` will simply have no matching rule and default to white, which is correct (management is not a protocol server).

To:
```tsx
className={`server-card server-card--${healthState} ${protocolClass} ${isAnimating ? 'server-card--pulse' : ''} ${isSelected ? 'server-card--selected' : ''}`}
```
