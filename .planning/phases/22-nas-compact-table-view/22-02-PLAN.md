The chevron in each row should toggle the expanded state. Important: the chevron click should call `setExpandedServer` and stop propagation so that the row click (`onRowClick`) is NOT triggered simultaneously. The rest of the row (clicking anywhere except chevron) should still call `onRowClick` to open the details panel.

```typescript
const handleChevronClick = (e: React.MouseEvent, serverName: string) => {
  e.stopPropagation();
  setExpandedServer(prev => prev === serverName ? null : serverName);
};
```
