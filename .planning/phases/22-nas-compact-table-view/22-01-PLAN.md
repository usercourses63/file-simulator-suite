Create `NasTable.tsx` with the following interface and implementation:

**Props interface (NasTableProps):**
```typescript
interface NasTableProps {
  servers: ServerStatus[];           // NAS servers only (pre-filtered by parent)
  onRowClick: (server: ServerStatus) => void;  // Opens details panel
  showMultiSelect?: boolean;
  selectedIds?: Set<string>;
  onToggleSelect?: (id: string) => void;
  onDelete?: (server: ServerStatus) => void;
  dynamicInfo?: Record<string, { isDynamic: boolean; managedBy: string }>;
}
```

**Grouping logic:**
1. Create a helper function `getGroupKey(server: ServerStatus): 'input' | 'output' | 'backup' | 'other'` that checks:
   - First check `server.directory` field: if it contains "input" -> 'input', "output" -> 'output', "backup" -> 'backup'
   - Fallback: check `server.name` for the same keywords
   - Default: 'other'
2. Group servers into a `Map<string, ServerStatus[]>` using `getGroupKey`.
3. Render groups in fixed order: input, output, backup, other (skip groups with 0 servers).

**Sub-group header:**
Each group renders a header row spanning the full width showing:
- Group label: capitalize first letter (e.g., "Input Servers", "Output Servers", "Backup Servers")
- Server count in parentheses: "(3)"
- Aggregate health summary: compute using `getHealthState` from `../utils/healthStatus`:
  - If all servers are healthy: show "All Healthy" in green
  - If some but not all healthy: show "X/Y Healthy" with yellow color
  - If none healthy: show "All Down" in red

**Data rows (one per server):**
Each row is a `<div>` with class `nas-table__row` (NOT an HTML `<table>` -- use CSS grid for alignment). Columns:
1. **Status dot** (8px circle): colored by health state using existing `--color-healthy`, `--color-degraded`, `--color-down` vars
2. **Server name**: truncated with ellipsis, use `server.name`. Strip the common prefix `file-sim-file-simulator-` if present to show just `nas-input-1`, `nas-output-2`, etc. Keep full name for dynamic servers.
3. **Directory**: show `server.directory` in monospace font, muted color
4. **Latency**: formatted as `Xms` or `X.Xs` (>1000ms). Show `--` if undefined.
5. **Port**: show `server.nodePort` or `server.port`
6. **Dynamic badge** (conditional): if server is dynamic per `dynamicInfo`, show a small "Dynamic" badge; if Helm-managed, show "Helm" badge. Use same badge classes from App.css (`.badge--dynamic`, `.badge--helm`) but smaller.
7. **Chevron icon** (right side): a `>` character or SVG chevron indicating the row is clickable. This is purely decorative for now (expand behavior added in plan 22-02).

**Row click handler:** Call `onRowClick(server)` when any row is clicked.

**Multi-select support:** If `showMultiSelect` is true and server is dynamic (check `dynamicInfo`), show a checkbox at the start of the row (same pattern as ServerCard). Checkbox click calls `onToggleSelect` and stops propagation. If `selectedIds` has the server name, apply `nas-table__row--selected` class.

**Delete button:** If server is dynamic and `onDelete` is provided, show a small delete icon on hover (same pattern as ServerCard's `.server-card-delete`).

**CSS file (NasTable.css):**
Use BEM naming with `.nas-table` as block. Key selectors:
- `.nas-table` — container, no outer border, fits within existing `.server-section`
- `.nas-table__group` — a group wrapper
- `.nas-table__group-header` — sub-header row: flex layout, align items center, height ~32px, background `rgba(20, 184, 166, 0.06)` (NAS teal tint), left border 3px solid `var(--protocol-nas)`, padding-left 12px, font-weight 600, font-size 0.875rem
- `.nas-table__group-health` — health summary text, font-weight 400, margin-left auto
- `.nas-table__group-health--healthy` — color: `var(--color-healthy)`
- `.nas-table__group-health--mixed` — color: `var(--color-degraded)`
- `.nas-table__group-health--down` — color: `var(--color-down)`
- `.nas-table__row` — CSS grid row: `grid-template-columns: 12px 1fr 120px 80px 70px auto 24px;` (status-dot, name, directory, latency, port, badge, chevron). Height: 40px. Align items center. Gap: 8px. Padding: 0 12px. Cursor: pointer. Border-bottom: 1px solid `var(--color-border)`.
- `.nas-table__row:hover` — background: `rgba(20, 184, 166, 0.04)` (subtle NAS teal hover)
- `.nas-table__row--selected` — outline: 2px solid `var(--color-primary)`, outline-offset: -2px
- `.nas-table__row--down` — background: `rgba(239, 68, 68, 0.04)` (subtle red for down servers)
- `.nas-table__cell--name` — font-weight 500, font-size 0.875rem, overflow hidden, text-overflow ellipsis, white-space nowrap
- `.nas-table__cell--directory` — font-family monospace, font-size 0.75rem, color `var(--color-text-light)`
- `.nas-table__cell--latency` — font-size 0.8125rem, text-align right
- `.nas-table__cell--port` — font-size 0.75rem, color `var(--color-text-light)`, text-align right
- `.nas-table__cell--badge` — flex-shrink 0
- `.nas-table__cell--chevron` — color `var(--color-text-light)`, font-size 0.75rem, text-align center
- `.nas-table__status-dot` — width 8px, height 8px, border-radius 50%, flex-shrink 0
- `.nas-table__status-dot--healthy/degraded/down/unknown` — use corresponding `--color-*` vars
- `.nas-table__delete-btn` — same pattern as `.server-card-delete` but smaller (20px), opacity 0 by default, visible on row hover
- `.nas-table__checkbox` — similar to `.server-card-checkbox` pattern
